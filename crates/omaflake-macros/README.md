# omaflake-macros

[omaflake](https://omaflake.dev) – clean, disposable NixOS and macOS VMs on Apple silicon and Linux, declared in Nix ("recipes"), started from a menu bar app or the command line `omaf`.

omaflake's procedural macros: the keyed error macro behind `omaflake-core`'s `vm_err!` – an error's format string is
its translation key. A part of omaflake, released with it.
