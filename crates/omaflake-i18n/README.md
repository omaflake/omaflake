# omaflake-i18n

[omaflake](https://omaflake.dev) – clean, disposable NixOS and macOS VMs on Apple silicon and Linux, declared in Nix ("recipes"), started from a menu bar app or the command line `omaf`.

Translations of omaflake's Rust interfaces (`omaf ui`, the Linux app): generated from the macOS app's
`Localizable.strings`, keyed by the English text. A part of omaflake, released with it.
