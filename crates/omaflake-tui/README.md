# omaflake-tui

[omaflake](https://omaflake.dev) – clean, disposable NixOS and macOS VMs on Apple silicon and Linux, declared in Nix ("recipes"), started from a menu bar app or the command line `omaf`.

omaflake's terminal interface – `omaf ui` (ratatui): VMs, images, recipes, builds, the Doctor and settings, as in the
app. A client of the page models the core serves; it holds no logic of omaflake's. Run it through
[`omaflake`](https://crates.io/crates/omaflake) (`omaf ui`).
